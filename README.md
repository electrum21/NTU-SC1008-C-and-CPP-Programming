# NTU SC1008 - C and C++ Programming

Welcome to my NTU SC1008 repository! This repository organizes my solutions, code implementations, and practice materials for learning procedural programming in C and object-oriented programming in C++.

---

##  Repository Structure

The repository is split into two primary language tracks, following the curriculum structure:

### 1. C Programming (`/C`)
* **`Tutorials/`** - Guided tutorial problem sets and weekly exercises.
* **`APAS Qns/`** - Automated Programming Assessment System questions and problem solutions.
* **`Labs/`** - Practical coding lab exercises and hands-on implementations.
* **`Mock Test/`** - Practice papers and mock tests for exam preparation.

### 2. C++ Programming (`/C++`)
* **`Labs/`** - Practical lab exercises covering object-oriented concepts.
* **`Tutorials/`** - Weekly tutorial problem sets and application tasks.
* **`Assignments/`** - Graded programming assignments.
